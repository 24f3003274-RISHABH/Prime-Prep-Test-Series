# Services Layer

Business logic layer for PrimePrep:
- `authService.js`: Authentication, password hashing, token generation
- `subjectService.js`: Subject management and configuration
- `testService.js`: Test series, tests, question handling
- `excelImportService.js`: Spreadsheet parsing and transactional batch insertion
- `testEngineService.js`: Server-side timers, attempt lifecycle, grading
